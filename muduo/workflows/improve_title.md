# Workflow: Improve Title（标题诊断与优化）

用途：Mode 3 改标题。标题是"注意力市场定价工具"+"承诺契约"，优化必须同时服务：平台信号、人类注意、内容兑现。

## 输入
- **场景 A（改标题）**：原标题（必需）、内容主题或正文摘要（必需）、平台（必需）、受众、传播目标。
- **场景 B（新内容交付，无原标题）**：内容主题或正文摘要（必需）、平台（必需）、受众、传播目标。
  从中心命题 + 最强素材直接生产候选标题。
  **铁律（Title First）：任何内容交付物——长文、文章、脚本、推文串、改写稿——
  交付前必须走完本工作流并产出合格标题；无合格标题 = 交付不完整，禁止先交内容后补标题。**

## 流程
1. **确定标题在该平台的职能**（读 adapter 的 title_role/cover_role）：
   - 小红书：封面大字为主标题，笔记标题辅助搜索 → 标题重关键词，封面重情绪
   - 抖音：标题弱、开场重 → 标题主要服务搜索与信息流文字层
   - 公众号：标题即封面，决定打开率 → 全部注意力预算在标题
   - 知乎：标题=问题本身 → 重需求匹配
   - X（thread 推文）：首条推文即标题职能 → 重金句化与身份信号
   - X（Articles 长文）：标题在 feed 卡片**独立作战**，无首条推文兜底 → 标题本体必须自带
     完整钩子与读者利益，禁止把传播力寄托在 thread 首条上
   - YouTube：标题与缩略图互补分工
2. **诊断原标题**（仅场景 A；场景 B 跳到步骤 3）：
   - 相关性信号：目标人群能否 1 秒内认出"与我有关"？（top_down_attention_guidance）
   - 信息差：有没有"不知道的东西"？（curiosity_gap, B）
   - 具体性：抽象名词堆砌还是具体可感？（processing_fluency / specificity_effect）
   - 身份信号：有没有人群身份词、场景词？（social_identity_theory / identity_signaling）
   - 承诺-兑现：标题承诺正文能兑现吗？（expectation mismatch 是高点击低停留首因）
   - 情绪：唤醒水平合适吗？（过高→标题党透支信任；过低→无人停留）
3. **生成候选**：按诊断结果选择策略组合（不机械套模板）：
   - 缺相关性 → 加身份词/场景词
   - 缺信息差 → 加具体未知点（结果/反差/代价），不用"震惊体"
   - 流畅性差 → 减少抽象名词、缩短从句、用具体数字
   - 平台需要 → 嵌搜索关键词（搜索型平台）
   **标题五项必查清单（强制，与 SKILL.md §3 品类必查清单同步）**：
   specificity_effect / processing_fluency（画面构建）/ emotional_arousal /
   identity_signaling / concreteness_in_language——逐项评估，
   每条候选至少命中 3 项（逐项给一句依据），全不沾边的候选直接废弃。
   **传播力上限检验（第二道门——五项全过 ≠ 合格）**：
   a) **读者利益必答**：目标读者 3 秒内能答出"点开我能得到什么 / 这与我何干"；
      作者视角（我做了什么）不自动满足本条——identity_signaling 优先查读者身份与痛点，
      作者身份次之；
   b) **低唤醒自指词一票否决**：标题本体含"实录 / 合集 / 漫谈 / 浅谈 / 随笔 / 纪要 /
      总结 / 心得"等文档形态自指词直接降级废弃——它们描述文档形态而非内容价值，
      流畅性不受损但唤起与好奇归零（教训：三篇"实录"后缀全部放行）；
   c) **行话门槛（category_entry_points）**：标题本体术语必须落在目标读者的品类入口词
      范围内；泛技术读者场景下，行话（如 N+1 / Mock / 规约）要么配解释性短语，要么换画面表达；
   d) **系列标识不占标题本体**：系列感用"（上）（中）（下）"与正文首行引言区承载。
4. **每条候选标题自检**：
   - 兑现检查：正文能兑现吗？
   - 边界检查：该策略对本内容类型成立吗？
   - 平台检查：触发限流词/违规词吗？
5. 输出 3-5 个候选 + 每条说明：机制依据、预期信号、适用条件、**逐条优劣对比**；
   给出推荐项与理由，**等用户选择后才定稿**（铁律 9 决策门禁，禁止直接定稿）。

## 输出格式
```text
## 原标题诊断
[问题1] 机制：xxx（证据 x）；[问题2] ...

## 候选标题
1. 《...》—— 依据：specificity_effect（B）+ 身份信号；预期：搜索命中↑
   适用：...；不适用：...
2. ...

## 提醒
- 封面/首图与标题的分工（平台差异）
- 标题承诺必须兑现，否则点击高停留低（expectation mismatch）
```

## 禁止话术
- "标题要加数字"（无条件版）→ 数字只是 specificity 的一种实现，情绪共鸣型标题可不用
- "标题要制造焦虑" → 高唤醒有路径但 manufactured outrage 是反模式
- 任何"一定要/必须/万能公式"表述
