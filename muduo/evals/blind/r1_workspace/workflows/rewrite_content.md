# Workflow: Rewrite Content（内容重写）

用途：Mode 3 直接改写。**前置条件：已跑过 analyze_content.md 完成诊断**；无诊断不重写。

## 输入
原文（必需）、诊断结论（必需）、平台、受众、传播目标、品牌约束（语气/禁词/必提信息）。

## 流程
1. **确认改动范围**：与用户确认改哪些层（只 Hook？结构？全篇？），
   以及不可动的东西（事实、数据、品牌话术、法律表述）。
2. **按瓶颈定位重写策略**：
   - 停留流失 → 重排结构：价值前置（serial_position_effect）、每段留"下一步理由"（suspense_structure）、砍认知过载（information_overload / extraneous_cognitive_load）、具体化（concreteness_in_language）
   - 读完不信 → 加可信信号：具体细节>形容词（specificity_effect）、承认局限（trust_calibration）、可验证来源（source_credibility_model）；禁 fake social proof
   - 无人互动 → 预埋评论靶子：具体分歧点（subtle controversy）、低门槛回应位（politeness_face_theory）、给立场词表（identity_signaling）
   - 无人转发 → 补转发言口：身份表达句（"转给那个...的人"）、利他理由（utility+empathy）、社交货币（stepps_sharing_framework 中的 social currency）
   - 无人行动 → 摩擦审计（friction_reduction）：步骤≤3、给默认选项（default_option_effect）、损失框架合规使用（loss_aversion 边界内）、承诺一致性钩子（小承诺先行 foot_in_the_door）
3. **重写执行**：
   - 保留作者语言风格（Style Transfer），只改结构/钩子/信号层
   - 每处改动标注对应机制（内部注释，交付时按需展示）
   - AI 时代附加：给可验证细节留位（authenticity_premium）、避免模板化行文（ai_content_saturation 中的同质化风险）
   - **事实边界（铁律 10）**：一切事实性细节（数字/时间/动作/结果/引语）溯源到源材料，无法溯源的细节禁止写入（含"合理润色"）；引语逐字、可截断不可改写；推演内容显式标注且不得续写成已发生的处置动作
4. **重写后自检**：
   - 兑现闭环：标题/Hook 承诺是否全部兑现？
   - **标题门禁（铁律 3 Title First）**：交付稿的标题是否执行了 improve_title.md 五项必查
     清单（命中 ≥3 项）**并通过第二道门（传播力上限检验：读者利益必答 / 低唤醒自指词
     一票否决 / 行话门槛 / 卡片独立性）**？改写改变内容重心时，原标题必须重走清单。
   - 认知负荷：目标读者 1 遍能懂吗？
   - 兑现-信号-目标对齐：CTA 是否仍是原目标？
   - 伦理检查：无操纵/无虚假社会认同/无恐惧滥用？
   - **事实边界核对（铁律 10）**：事实细节逐项可溯源？推演已标注且未写成实做？
   - **平台数值门禁（铁律 11）**：交付物涉及平台硬限制时逐条核算（如推文 ≤280 units：CJK=2/ASCII=1/emoji=2/链接=23），超限即改并留痕。
5. 输出：改写稿 + 改动说明（哪里、为什么、机制、边界）。

## 体系完整性保护（合订/系列/多环节内容）

源内容是由多个独立环节构成的完整体系时（系列文章、方法论链条、多篇章合订、流程 SOP）：
1. 传播学优化的对象是**语言、节奏、钩子、信号层**，不是体系环节——作者当年单独写成每一篇，
   即意味着每一篇都是体系的关键环节，砍环节 = 砍体系；
2. 每个源篇/环节必须在成稿中保留可识别的完整叙事单元：环节名、核心主张、关键案例、
   金句、产出物逐项映射，链条不断链；
3. 删除/合并环节必须显式列出清单（砍了什么、为什么、读者会失去什么），经用户确认，
   **禁止静默删减**；
4. 字数预算按"保留底座"计算（体系完整所需的最小篇幅），不以压缩率为目标；
5. **结构映射表先行**：动笔前先产出"源篇 → 成稿章节"对照表给用户确认，再写正文。
6. **系列交叉对轴（铁律 11）**：跨篇引用（预告标题、回链、系列编号、行为目标口径）必须与各篇
   最终定稿逐一交叉核对——预告引用的标题必须与目标篇 H1 一字不差；交付前重验一轮。

## 输出格式
```text
## 改写稿
（全文）

## 改动说明
| 位置 | 改动 | 机制（证据） | 为什么 |
|---|---|---|---|

## 平台适配备注
（adapter 相关角色字段提示）

## 边界
本改写适用于...；不适用于...（如受众/目标与诊断假设不符需重跑）
```

## 禁止
- 无诊断全文重写（推倒重来要说明理由）
- 为效果加入虚假数据/虚假案例/伪权威
- 把作者的事实性内容改错
